# The publication sites of a landed install, read by publication_order.py.
#
#   <cells> <function> <kind> <object> <ordinal>/<count> <order> ["<anchor>"]
#
# <cells>: comma-separated ARM.WRITE.RELEASE patterns (fnmatch), or
# "reference" for code no cell compiles differently: the reference tree checks
# those rows, and they name their functions' accesses in every tree.  <kind>:
# load, store, rmw (any read-modify-write, a compare-exchange included), init
# (an atomic_init; markers only), call, or addr, sink and ref (below).
# <object>: the last member or identifier of the access's first argument; for
# a call, the callee.  <ordinal>/<count>: the access's place among the
# function's accesses of that kind and object, and their number, as the cell
# compiles the function; "-/<count>" for a call (the number of calls) and for
# a marker.  <order>: what the access must keep: acquire, release or acq_rel,
# and for a compare-exchange "/acquire" when its failure order must acquire
# too; "-" for a call, which pins only that the path goes through the callee,
# and for a marker.  <anchor>: required where the group holds accesses the
# register does not require the same way; it must occur in this access's
# context (its innermost block's header and its statement, up to the access)
# and in no other access's of the group.
#
# Only the half that carries the edge is required; where several accesses
# each carry it, the row's note says which one the register keeps.  An
# object is its name; the registered names are those a required row or a
# sink row names.  Every atomic operation (atomic_init included) whose
# object is a registered name, and every one in a function of libs/ whose
# first argument is not exactly "&<operand>" (an access through a pointer
# variable or a cast, whatever it reaches), must belong to a group some row
# names; where the argument is "&<operand>", the operand's object must be
# the access's.  The groups that carry no edge of a landed install are
# listed by marker rows, each bounding its group's count from above; that a
# marked group carries no edge is a reviewed claim the check does not judge.
#
# The address of a registered object may be taken only as the first argument
# of an atomic operation or of atomic_init, or of a function a sink row names
# ("<cells> <callee> sink <object> -/1 -": the callee's own accesses are
# checked); an addr marker ("<cells> <function> addr <object> -/<n> -") bounds
# the addresses a function takes otherwise.  Every arts_net_rdzv_expect call
# names its continuation by a ref row, which counts the calls exactly.  The
# check covers ordinary edits written in the project's style;
# publication_order.py's docstring lists what it refuses and the limits it
# does not judge.
#
# `python3 publication_order.py ... --list <function>,...` prints the accesses
# of functions as a cell compiles them, with each access's context.
